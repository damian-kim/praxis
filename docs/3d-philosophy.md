# Instrumented Reality

Instrumented Reality treats a simulated world as a legible machine: every surface exists both as spatial composition and as measurable constraint. Warehouse aisles form strong perspective corridors, shelves establish rhythm and occlusion, and the agent’s luminous route cuts through that volume as a temporal record. Seeded variation changes the placement of task objects without sacrificing reproducibility, so every episode is distinct but scientifically recoverable.

Light is functional evidence. Cool ambient illumination separates stable architecture from a dark ground plane; warm task objects and acid-green agent signals form a strict visual hierarchy. Contact creates a brief red field at the precise location of a limit violation. This meticulously crafted visual algorithm should make physical state readable before a user studies a single number.

The camera is an investigative instrument rather than automatic spectacle. A carefully chosen oblique overview reveals route, aisle clearance, and vertical scale, while deliberate orbit and zoom controls let an engineer inspect contact geometry. The observer follows live state continuously without stealing camera control, reflecting the painstaking interaction tuning expected from a master-level technical visualization.

Motion is reconstructed from immutable frames. Wheels rotate, the manipulator carries its payload in three-dimensional space, route segments accumulate, and contact energy breathes briefly around the chassis. This living system derives animation from recorded evidence rather than decorative randomness; its smoothness and timing should feel refined through countless iterations by someone fluent in both simulation and computational aesthetics.

Controlled variation enters only through a seeded generator shared with the scenario contract. Shelf architecture remains a stable reference while obstruction angle and package placement vary inside declared envelopes. The result should feel like a deeply engineered evaluation instrument: a master-level implementation whose beauty emerges from clarity, reproducibility, and the continuous transformation of data into spatial understanding.
